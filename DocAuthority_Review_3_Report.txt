1.1 PROBLEM STATEMENT & CORE INNOVATION
----------------------------------------
In enterprise consulting environments, corporate knowledge is fragmented across 
PDFs, chat records, meeting transcripts, and emails. Employees frequently rely 
on unapproved draft versions because standard search engines naively rank files 
based only on the newest file modification timestamp.

DocAuthority resolves this by implementing a deterministic Multi-Factor Authority 
Resolver Algorithm that scores candidate document versions:
  - Approval Status Score  : Max 50 Points (APPROVED=50, PENDING=20, DRAFT=10, ARCHIVED=0)
  - Department Ownership   : Max 25 Points (verified owner bonus)
  - Chronological Recency  : Max 25 Points (version update order)

KEY INNOVATION: An older APPROVED version (50 + 15 = 65 pts) outranks a newer 
DRAFT version (10 + 25 = 35 pts), completely eliminating draft leakage.
