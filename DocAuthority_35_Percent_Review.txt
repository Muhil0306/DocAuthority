1. ABSTRACT
--------------------------------------------------------------------------------
In modern consulting firms and enterprise environments, corporate knowledge is 
fragmented across documents, chat records, and meeting files. Employees frequently 
struggle to identify the single officially approved version of a policy or guideline. 
Existing document retrieval systems rely on keyword matching or latest modified dates, 
often leading to the accidental retrieval of unapproved draft documents or outdated 
policies. 

DocAuthority is a full-stack enterprise web application designed to solve knowledge 
fragmentation. It implements a multi-factor Authority Resolver Algorithm that ranks 
and selects authoritative document versions using approval status, ownership verification, 
recency, role-based access permissions, and exact source citations.

--------------------------------------------------------------------------------
2. PROBLEM STATEMENT
--------------------------------------------------------------------------------
Consulting firms manage thousands of evolving documents across departments (Finance, 
HR, Operations, Strategy, Technology, Risk & Compliance). Traditional search engines 
exhibit key critical flaws:
- They prioritize the newest file modified date, which frequently selects unapproved 
  draft versions over official approved policies.
- They lack integrated Role-Based Access Control (RBAC), risking data leaks of restricted 
  documents during search.
- They do not provide traceable, verifiable source citations (file name, page, section).

--------------------------------------------------------------------------------
3. OBJECTIVES AND SCOPE
--------------------------------------------------------------------------------
The primary objectives of the DocAuthority project are:
- Develop a deterministic Authority Ranking Resolver to score document versions out of 100.
- Implement strict Role-Based Access Control (RBAC) filtering prior to document ranking.
- Build an enterprise-grade web application UI with executive dashboards, search interfaces, 
  and administrative control panels.
- Provide automatic version rollback and comprehensive system audit logging.
- Evaluate the system against a baseline search model to demonstrate measurable accuracy gains.

--------------------------------------------------------------------------------
4. PROPOSED SYSTEM METHODOLOGY & RESOLVER ALGORITHM
--------------------------------------------------------------------------------
The core of DocAuthority is its 3-Stage Resolution Pipeline:

Stage 1: Access Control & Status Filtering
- Checks the user's role against allowed document roles (Consultant, Manager, HR, 
  Finance, Administrator).
- Removes archived and restricted document versions before evaluation.

Stage 2: Authority Scoring (Total: 100 Points)
- Approval Score (Max 50 Points): APPROVED = 50 pts, PENDING = 20 pts, DRAFT = 10 pts, 
  REJECTED/ARCHIVED = 0 pts.
- Ownership Score (Max 25 Points): Awarded for verified departmental document owners.
- Recency Score (Max 25 Points): Dynamically calculated based on version order. 

*Key Innovation*: An older APPROVED version (50 approval + 15 recency = 65 pts) outranks 
a newer DRAFT version (10 approval + 25 recency = 35 pts), preventing draft leakage.

Stage 3: Citation Generation & Response
- Returns the highest-ranking version along with an exact citation (file name, page number, 
  section) and a detailed scoring breakdown.
